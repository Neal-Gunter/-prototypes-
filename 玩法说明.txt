========================================
  玄 界  XUANJIE  ·  拼 刀 试 炼
========================================

【怎么玩 · Windows】
  双击 XUANJIE.exe 就能直接玩，不需要装 Godot、不需要联网。
  （首次启动 Windows 可能提示"未知发布者"，选"仍要运行"即可）

【怎么玩 · 安卓】
  双击（点击）XUANJIE.apk 安装，桌面出现「玄界 XUANJIE」图标，点开即玩。
  · 安装：把 XUANJIE.apk 传到手机（微信 / QQ / 数据线 / 网盘都行）→ 点击它
    → 系统问"是否允许安装未知应用"时选允许 → 安装 → 打开
  · 系统要求：Android 7.0（API 24）及以上，arm64 处理器（近几年的手机都是）
  · 屏幕：自动横屏（重力感应，左右横握都行），已开启沉浸式全屏，隐藏状态栏
  · 包体约 40 MB，内含 arm64 引擎 + 中文字体 + 全部音效
  · 签名：正式签名密钥在 keystore/xuanjie.keystore
    （包名 com.xuanjie.blade，版本 1.0 / versionCode 1）
    以后要发新版本必须用同一个 keystore 签名，否则手机会拒绝覆盖安装，
    只能先卸载旧版
  · 手机上没有键盘，屏幕两侧会自动浮出虚拟按键（PC 版不会显示）
  · 想临时在 PC 上看看手机布局：XUANJIE.exe -- --shot --touch

【阴阳走位 · 2.5D 纵深】（R9 新增）
  这一版不是横版贴图，场地是有「深度」的：
  从最贴镜头（阳）到最贴后墙（阴）是一条连续的纵深轴。

    · 每个角色都有一个深度坐标 z：0 = 贴镜头，1 = 贴后墙。
    · 越往阳，人越大、站得越低；越往阴，人越小、站得越高。
      这就是「近大远小 + 近低远高」，不需要任何 3D 模型。
    · 谁挡在谁前面也是按 z 排的：站在你前面（阳）的敌人会盖住你。
    · 地面是一条真的向后延伸的地板：有透视收拢的接缝、深度横线，
      地板后沿立着一排石柱，画面最前还有一层近景剪影（垂链 / 立柱）。

  【关键：命线】
    深度差超过 0.30 就「不在同一条命线上」——你的刀会从对方身前划过，打不着，
    对方的刀也一样打不到你。所以纵深不只是好看，它是一件战术工具：

      想躲开正面那一刀     → 按 外 / 里 错开身位（错开 0.3 以上就安全）
      想补刀 / 收人头       → 先按 里 / 外 对齐，再挥刀
      被围住的时候          → 往一侧拉开纵深，能把敌人摊成一条线逐个处理

    左下角有一个竖直的「深度条」，光点就是你自己的 z；
    条上有一段浅色容差带，光点在带内表示当前目标打得着。

  【各状态下的深度行为】
    · 杂兵：追击时轻微靠向你，出招瞬间会明显贴上来（更凶），收招后又退回去。
    · Boss：跟得更稳，不会因为出招大幅漂移，但依然会随你走位。
    · 飞行敌人：深度固定，只在横向俯冲。
    · 分身：刷在你左右两侧 ±0.26 的深度上，所以经常需要错身位才砍得到。
    · 死亡复活：深度复位到默认站位（0.34）。

  【手感提示】
    纵深走位速度是 0.90/秒（约 1.1 秒从最里走到最外），比横向移动慢，
    所以它是「微调身位」用的，不是逃跑手段 —— 躲刀还是靠冲刺和纵深错位。
    但剑意交锋前的半拍，错一点身位往往比硬挡更划算。

【灵力（左上角绿条）】
  除了走路，几乎所有主动动作都要花灵力：

    挥刀      每段不同，且**每把武器各不相同**（R12 起按段位表）：
                剑    9 / 11 / 16
                长枪  11 / 13 / 19
                双刀  6 / 7 / 10 / 14（四段）
                符剑  — / — / 7（远程两段不吃灵力，吃符力，见 核心二十二）
    冲刺      20
    格挡      举盾 11/秒，每挡下一刀再花 9（精准格挡只花 40%）
    蓄力斩    按蓄力等级递增，绝招另计

【攻速成长（道蕴球右边那条细条）】
  这一版主角开局是「手生」的：初始攻速只有 0.78 倍，出刀偏慢。
  一直打下去会越来越顺：

    · 统计最近 10 秒内你出了多少刀，刀越多热度越高。
    · 连打满 26 刀 ≈ 持续进攻 20 秒 → 攻速到顶 1.34 倍。
    · 热度 0 → 100% 是慢慢涨上去的（不是一刀到位），掉也是这样。
    · 只要 5 秒内没有一刀砍到敌人身上，热度就开始往下掉。
    · 剑意交锋、格挡不会掉热度（只要还在打）。

  细条颜色从淡蓝（慢）渐变到金黄（快），旁边会写出当前倍率「攻速 ×1.34」。
  满热度时条尾会有个跳动的小金点。

  所以打 Boss 的节奏是：先花十几秒把热度打上去，再进阶段输出；
  中途躲技能躲太久，攻速会掉下来，输出窗口就变短。

【核心一：剑意交锋】
  敌人举刀时，刀身会亮起红光，同时地上会出现一道红色的刀路预示弧。
  在这道红光出现的瞬间挥刀迎上去 —— 两把刀撞在一起就是「剑意交锋」。

  · 剑意交锋成功：双方被震开，敌人进入硬直（这时候可以随便砍），
    屏幕顿帧 + 震屏 + 火星，并回复道蕴。
· 悟道·剑意交锋：只在敌人「攻击阶段」（刀身亮红光的瞬间）且是本次挥砍的
    「第一刀」撞上去才触发 —— 之后继续贴着只会算普通剑意交锋。
    悟道·剑意交锋会触发子弹时间、更强震屏与金光，敌人硬直更久，道蕴回复翻倍。
· 出刀太早（敌人还没举刀）或太晚（已过攻击窗口）→ 被砍中掉一格血。

  节奏是：看到红光 → 数半拍 → 按 J。

【核心二：硬直度（敌人头顶的黄色细条）】
  这是这一版新增的"削韧"机制。两种行为会给敌人累积硬直度：

    剑意交锋成功    +20（悟道·剑意交锋 +12，三段连斩剑意交锋再 +10）
    格挡成功    +15（精准格挡 +26）

  硬直条会慢慢自己回落（1.5 秒不挨打就开始掉，13/秒）。
  打满 → 「硬直打破」：敌人进入 2 秒左右的长硬直，动弹不得，
  这是白送的一整套连斩窗口。

  打 Boss 的时候这条尤其重要：Boss 血厚，靠硬直打破能多打出两三轮伤害。
  Boss 的硬直条会显示在血条下面（橙色）。

【核心三：连招模组 · 四把兵器四套连招】（R12 重写，R29 加第 4 把）
  J 不是只能砍一下。在收刀前再按 J 会接下一段。段数、手感、收刀长短
  **每把兵器都不一样** —— 选兵器就是选一套动作，不只是选数值：

    单手剑  3 段   斩 / 斩 / 斩
            收刀最早可取消（35%），打不过就退得掉。最稳的一把。

    长 枪   3 段   突 / 突 / 突
            刀锋长 45%，出刀时若前方 190px 内有人会自动多冲一截；
            但**贴脸（52px 内）伤害 -1** —— 枪杆没有杀伤力，必须用枪尖打人；
            收刀要走到 78% 才能取消，砍空就得站着挨。

    双 刀   4 段   斩 / 斩 / 旋 / 旋
            攻速 +25%、灵力 -20%，但单段伤害最低、刀锋最短（0.88）；
            换来的是**最高的护体罡气压制**（一套压制量约等于单手剑的两倍）。

    符 剑   3 段   符击（远程）/ 符击（远程）/ 剑斩（近战突进）
            唯一一把远程 + 近战混合武器：前两段把符射出去（不吃灵力，
            每段吃 1 格**符力**），第三段才贴身。远程段没有刀锋，
            所以也弹不回落幕弹 —— 详见「核心二十二」。

  · 取消窗口：收刀进行到一定比例后，按闪避或按住格挡可以直接断掉后摇，
    立刻转成冲刺 / 举盾。HUD 攻速条下面那行会变成绿色并显示「可取消」——
    看到绿色就是现在能撤。
  · 动作标签：每一段都带一个标签（斩击 / 突刺 / 回旋 / 符击），部分法宝认标签
    而不认武器 —— 见 核心七 里的「回锋 / 桩步 / 余音」。
  · 段位都命中会累积「连斩 ×N」计数（右上角）。每一段都带前冲，连斩会
    自然把人往前推。

【核心四：格挡】
  按住 L 进入格挡姿态，移动速度降到 32%。
  正面来的刀会被挡下，不掉血，但会涨「护体罡气」（左侧 0–100 的横条，R11 起）：

    普通格挡一刀 +18 护体罡气；被打中（没挡住）+25。
    护体罡气满了不即死，而是进入「道心失守」—— 详见 核心八。
    不挨打时护体罡气会自己回落。

  · 精准格挡：按下的前 0.15 秒内挡住，金光 + 敌人硬直 0.55 秒，
    不涨护体罡气（还倒扣一格），而且硬直度加得更多。
  · 格挡只能挡正面，背后来的刀照样掉血。
  · 第三阶段的 Boss 有一招「破防重击」是挡不住的（刀身泛暗红），
    看到它举这种刀要闪，不要举盾。

【核心五：移动 · 冲刺 · 灵力】（R9 起无跳跃）
  R9 把场地改成 2.5D 平面之后，**跳跃 / 二段跳 / 攀爬 / 空中下劈整套移除**，
  走位只剩两个自由度：横轴（左右）+ 纵深（里 / 外）。理由很实在 ——
  拼刀游戏要的是「站位与距离」，不是「高度」；多一条竖直轴只会让判定更难读。

  移动      235 px/s，加速 2400 px/s²，松手摩擦 2800 px/s²
            举盾时移速 ×0.32（挡着走等于慢走）
  冲刺      680 px/s 持续 0.16 秒，冷却 0.42 秒，耗灵力 20
            冲刺期间**无敌帧**能穿刀、穿绝招判定
  灵力      上限 100，停止消耗 0.55 秒后开始回：
            站着回 40/s，走动回 24/s
            挥刀每段 7~19（看武器段位）、冲刺 20、挡一刀 9、举盾 11/s
            灵力见底会「力竭」0.55 秒 —— 这段时间什么都做不了，别乱按

  纵深走位见下方「阴阳走位」：往里（阴）躲刀、往外（阳）贴脸输出。

【剑冢守 · 三阶段】
  每打空一次血，它会满血复活并进入下一阶段（血条上分 3 段，会显示当前阶段）。

  第一阶段
    · 二连斩，出刀偏慢，伤害 2 格。给你熟悉节奏用的。

  第二阶段
    · 攻速提升（抬刀时间 ×0.82），连段变成三连斩。
    · 【防御】偶尔摆出防御姿态（正面蓝色护盾）：
      这时候砍上去只会「挡下」，砍两下它会立刻反击。
      正确做法是停手，等它收盾再打；或者用剑意交锋。
    · 【远程剑气】拉开距离时会抬手聚一颗紫球，朝你直线射过来。
      这颗弹幕可以用刀砍回去（「弹反」），飞回去会打它自己 2 点血，
      用格挡也能挡下。

  第三阶段
    · 抬刀更快（×0.72），并解锁三个技能：
    · 【弹反】防御姿态下砍它有 50% 概率被弹反：
      你会被震开、硬直、掉一格血，它顺势反击。正面硬砍风险很高。
    · 【狂暴】每隔一段时间怒吼进入狂暴 4.5 秒：
      移速 +32%、突进更远、刀更快，身上冒出红色光环。
    · 【闪避】你正在出刀时，它会向后滑步闪开（带残影，闪避期间无敌）。
    · 【读招】每次决策有 50% 概率先读你的指令：
        你在挥刀 → 闪避或弹反
        你在举盾 → 用破防重击（挡不住）
        你在空中 → 对空斩
        你在冲刺 → 举盾等你
      它读招时头顶会飘出「读招 · 闪 / 破防 / 对空 / 挡」。
      所以第三阶段不能只靠一套连招，要变招、要骗它。

  打它的思路：
    1. 灵力留给闪避，别把三段连斩当平砍用。
    2. 它举盾时不要砍，绕着走或者用剑气弹反。
    3. 剑意交锋和精准格挡能把硬直条打满，破硬直后是最大的输出窗口。
    4. 第三阶段多用「砍一刀就收」的节奏，骗它闪避再追击。

【前世身 · 三阶段】（第三个 Boss，体型最小、招式最多）
  10 血 × 3 阶段，每打空一次血都会回满并进入下一阶段。
  它的"一阶段"就已经等于剑冢守的"三阶段"：读招 50%、弹反 50%、
  狂暴、闪避、三连斩、远程剑气、防御，全都一开始就有。

  第一阶段（= 剑主三阶段 + 范围震波）
    · 【范围震波】如果 10 秒内你一次都没受伤（一直在躲、一直没被打到），
      它会立刻跺地放一圈贴地扩散的橙色震波，半径 250。
      抬脚蓄力 0.85 秒 —— 跳起来（超过约 120 像素）或者冲出圈外都能躲。
      它每次放完有 9 秒冷却；只要你被打到过，计时就从头算。
      换句话说：躲得太完美反而会挨这一下，别一味龟着。
    · 其余招式与剑主第三阶段完全一致，只是抬刀更快（0.26 秒）。

  第二阶段（+ 闪现）
    · 【闪现】有几率原地消失（只剩一团残光），0.24 秒后出现在你背后
      62 像素处，落地瞬间随机接一招：突进斩 / 破防重击 / 远程剑气 / 范围震波。
      闪现期间无敌，砍不到。
      应对：看到它消失就往反方向挥刀，或者干脆拉开距离等它出现。

  第三阶段（+ 环境变暗 / 天雷 / 分身）
    · 【环境变暗】整片区域的光被吞掉，只剩你和它身上的一点冷光。
    · 【天雷】每 2~3.4 秒，你附近（±240 像素内）会落下一道雷：
      先有一根细光柱和地面收缩圈警示 0.62 秒，然后劈下来。
      站地上会被打中，跳起来（离地超过约 180 像素）能躲。
    · 【分身】一次放出 2 个半透明分身，各自会追着你砍，
      存在 20 秒后自己散掉，也可以提前打掉（2 血）。
      分身不吃硬直条，伤害 1 格。
    · 【双技】血量降到 20%（10 血里的最后 2 血）时，它每次出招都会
      同时用两个随机技能 —— 比如先闪到你背后，紧接着放范围震波。
      这时它身上会多一圈红环，看到红环就要按"要挨两下"来准备。

  打它的思路：
    1. 一阶段就得当成剑主三阶段来打：不能站桩连砍，要变招骗闪避。
    2. 躲技能的时候别完全不打 —— 10 秒不挨打会触发震波，
       而且 5 秒不砍中它攻速热度就会掉。
    3. 天雷落下前的那道光柱就是提示，看到光柱先离地。
    4. 分身别急着清，除非它们挡在你和本体之间；20 秒自己会散。
    5. 残血双技阶段，留灵力冲刺，别贪刀。

【尸解仙 · 无相】（R8 新增，尸解墓道 Boss）

    第二阶段抬刀略快，节奏要提前半拍。

【域外天魔】（R8 新增，天门 Boss）
  13 血 × 3 阶段，体型最小、出招最快（比前世身再快 14%）。
  · 招式池与前世身一致：读招 / 弹反 / 狂暴 / 闪避 / 三连斩 / 远程剑气 /
    防御 / 范围震波 / 闪现，第三阶段同样会「变暗 + 天雷 + 分身 + 残血双技」。
  · 因为体型小、位移快，刀锋容易落空 —— 长枪（刀锋 ×1.45）在这一关明显更稳，
    双刀虽然快，但刀短，很容易被它闪开后反打。
  · 打它的思路：把这一关当成前世身的「加速版」，所有窗口都短一截，
    多用「砍一刀就收」，靠剑意交锋和精准格挡攒硬直，而不是硬连三段。

【核心六：蓄力斩与绝招】（R6 新增，不能剑意交锋）
  按住 U / I 开始蓄力（主角会蹲下蓄力，脚下冒火花，刀身蓄起光弧）：

    · 蓄到约 0.4s 松手 → 蓄力斩（破防重击）：一道宽刀劈下，伤害 3，
      直接砸开敌人防御（无视格挡护体罡气），并给大量硬直。
    · 蓄满约 1.15s 松手 → 绝招：原地范围爆发（半径 210），秒杀周围杂兵、
      重创 Boss，命中越多连斩计数越高，自身短暂无敌。

  重要：蓄力斩和绝招都【不能剑意交锋、也不能被弹反】——
  剑意交锋判定在蓄力 / 绝招期间直接关闭（clash_rect 返回空），所以不要想用
  绝招去"拼"敌人的刀，老老实实靠普通挥刀 / 格挡去拼。

【核心七：肉鸽 · 法宝与房间】（R6 新增，参照《暖雪》）
  每清一间非 Boss 房，从 30 种法宝里随机给 3 个没拿过的，挑 1 件带走
  （下面 18 件是 R6–R13 的底子，R30 的 12 件逐条见「核心二十三」）：

    锋刃  三段连斩每段伤害 +1        疾风  攻速上限 +0.12，热度涨更快
    铁肺  灵力上限 +25，恢复更快      嗜血  每命中 3 刀回 1 血
    剑鞘  格挡护体罡气上限 +1（可挡 4 刀） 轻身  移动速度 +12%
    雷印  剑意交锋额外 +10 硬直度        蓄能  蓄力速度 +40%，绝招更早成
    铁壁  精准格挡窗口 +0.08 秒      灵息  开局道蕴 +40，治疗消耗 -8
    长锋  刀锋判定 +18%             守心  受伤后无敌时间 +0.4 秒

  R12 新增三件「认标签」的法宝（不认武器，只认你正在打的这一段是什么动作）：

    回锋  「回旋」段护体罡气压制 +45%    （双刀第三、四段吃满）
    桩步  「突刺」段取消窗口提前 30%  （补掉长枪收刀晚的短板）

    剑群  飞剑 +1 道，伤害 +1
    穿云  飞剑伤害 +1，命中回 3 道蕴（且可穿透）

  R30 再扩 12 件（剑 / 体 / 灵 各 4），**每一件都带代价或条件**：
    断念 / 追风 / 剑匣 / 残心 · 铁衣 / 反震 / 龟息 / 血怒 · 聚灵 / 符囊 / 阴眼 / 阳炎

  这 30 件按 3 个位次（剑 / 体 / 灵）归位，同套系拿满 3 件会触发质变 —— 详见上方
  「法宝套系 · 拿满 3 件质变」与 核心十「位次与流派」。

【核心八：护体罡气与道心失守】（R11 新增，只狼式躯干值）
  敌我双方各有一条护体罡气条，是一根「双向倾斜」的压力条，不是血：

    你的护体罡气：左侧横条（0–100）。普通格挡 +18 / 被打中 +25，满了进「道心失守」。
              道心失守 1.2 秒内不能行动（不即死），之后护体罡气清零重来。
    敌人护体罡气：Boss 血条下方那条细条。两条路能涨它 ——
              ① 悟道·剑意交锋：一次 +40%（快、险、省事）
              ② 连招压制：命中按段累积（剑 0.21 / 枪 0.25 / 双刀 0.44 套）
                 但敌人停手 2.2 秒后护体罡气会以 16%/秒 回落，所以压制必须连着打。

  · 敌人护体罡气满 → 进入「道心失守」（小怪 2 秒 / Boss 1.2 秒），此时靠近按 F（触屏点「刀」）
    可以直接「处决」：造成当前血量 25%（Boss 15%）的伤害，并清零它的护体罡气。
  · 道心失守窗口是白送的输出机会，也是打 Boss 的主要节奏点 —— 血厚靠硬直和道心失守磨。

【核心九：世界层 · 地图 / 故事 / 人物】（R14 新增）
  这一层不加机制，只让每一关「说一句话」：

  · 玄界之门：每关背景里都能看到一道门的剪影，越往深处越亮、越大。
    不用看 UI 也知道还剩几层。
  · 残 碑：每关起始房有一块碑，碑文随关卡变化 —— 那是「上一次轮回」留下的。
  · Boss 三句话：禁制时一句战前、进二阶段一句战中、被你杀死时一句临终。
  · 负匣人：商人房的游商，台词随关卡变化，关四会求你「别开门」。
  · 记忆回响：尸解墓道「铁链·深井」房会出现一个暗色剪影 —— 上一次轮回的你，
    轮廓光取你当前兵器的颜色。它不算 Boss，杀了不结算，只是拦路。
  · 叙事不拖慢肉鸽：所有台词**首次**完整播放，重开时压成一行短句，
    不会每次重开都逼你看一遍。

【核心十：位次与流派】（R13 新增，R16 扩格，暖雪式 Build）
  法宝不再「见一件拿一件」—— 它们要放进三个位次里，每个位次默认 3 格：

    剑位  ← 近战类 + 飞剑类（8 种）      体位  ← 守御类（5 种）
    灵位  ← 道蕴类（5 种）

  · 归位规则：每件法宝有自己的本位次，抽到时自动进本位。
  · 满了怎么办：**替换页**。清完一间房选法宝时，如果那个位次已经满了，
    会先弹出该位次现有的 3 件，让你选一件弃掉，再放新的。
    （宝箱溢出卖成 15 道蕴；商队溢出会拒绝交易并退还道蕴，不会白花钱。）
  · **扩容（R16）**：满了不一定要弃 —— 替换页顶部有「花 45 道蕴把这一位扩到
    4 格」，按 `F`（触屏点顶部按钮）即可，新法宝直接收下，一件不丢。
    每位最多扩一次（3 → 4），道蕴不够时按钮变灰并提示还差多少。
  · 左上角常驻显示「刃 2/3 ●●○」这样的格子，一眼看出还剩几格（扩容后是 4 格）。
  · **抽卡分层（R16）**：三选一不再纯随机 —— 你已经装了两格的位次权重 ×1.7，
    装满的位次掉到 0.12（几乎不出，出了也只是替换素材），飞剑流成立时剑位再 ×1.25。
    所以「顺着已经在走的路走」比硬凑更容易成 Build。

  **二次质变（R16）**：除了「同一位次凑 3 件」，还有一组**跨位次**的组合质变 ——
  要求「A 位装满 + B 位有某件指定法宝」：

    鞘 中 藏 锋   剑位满 + 体位有剑鞘   → 取消窗口再宽 15%（收刀更快能撤）
    不 动 如 山   体位满 + 灵位有灵息   → 格挡灵力消耗 −30%
    灵 息 不 灭   灵位满 + 剑位有长锋   → 道蕴获取再 ×1.3

  与套装质变**叠加**。HUD 流派名后面会追加金色小字（如「剑 修 · 鞘 中 藏 锋」）。

  流派名（装满位次就解锁，HUD 位次格下面常驻）：

    剑 修    剑位装满 → 全段护体罡气压制 ×1.2
    壁 守    体位装满 → 精准格挡窗口 +0.04 秒
    灵 御    灵位装满 → 道蕴获取 ×1.2
    飞剑流   剑位有飞剑类 + 灵位有 2 件道蕴类（跨位联动）→ 飞剑伤害 +1
    散 修    什么都没装满

  · 飞剑怎么用：**不用按新键**。有飞剑类法宝时，连招的最后一段会自动甩出飞剑：
      道数 = 你手上的飞剑类法宝件数（1~3）
      伤害 = 1 + 穿云(+1) + 飞剑流(+1)
    所以「把连招打完」本身就是远程输出，飞剑是连招打顺了的红利。

【核心十一：房间会说话】（R15 新增，环境叙事 + 2.5D 纵深）
  这一层不加任何新机制，只让每一间房「长成自己的样子」——
  换房不再只是换一波敌人。所有静物都是背景，**不进碰撞、不影响任何判定**。

  · 起始房（入口）：后墙一排竖刻痕（有人在这儿数过日子）、靠在地上的断剑
    （断了尖，旁边还躺着断掉的半截）、石台上将灭的残灯（火苗时有时无）。
  · 秘藏房：箱子旁边坐着一具骸骨 —— 腿伸开、头低着，开箱开到一半就死了。
  · 陷阱房：半透明的受害者残影，低头垂手、缓慢浮动，一直踩在同一个地方。
  · 商队房：负匣人站在阴影里，背上的大匣子有铜扣，兜帽下两点光，手边一根手杖。
  · Boss 房：门边会淡出一个**残影引导者**（见下）。

  · 伪楼层（只有尸解墓道「玄铁墓道」成立）：
      上排房（靠后墙）→ 后墙立两具横置铁棺，棺盖中缝透着一点磷光；
      下排房（靠镜头）→ 近处地面散落断铁链，链头翘起指向画面外。
      单层网格被读成两层 —— 纯视觉错位，网格本身没变。
  · 禁制内收（Boss 房）：四面禁制时，近景石柱会往画面中间挤、左右压暗，
    门关上的同时空间也变窄了。击败 Boss → 解锁 → 自动复原。

  · 残影引导者：Boss 房淡入一个站在门前的淡影，站定约 1.5 秒后说一句话。
    它是「上一个走到底的人」留下的一点残响 —— 只给方向暗示，不给答案：
      镇钟廊  「它不回头。你打它背后。」
      剑冢阶  「它的刀有两段。第二段才是真的。」
      尸解墓道  「门开的时候，别站在门口。」
      天门  「别数你砍了几下。数它还剩几次能站。」
    四关四句，重开只给省略号（和残碑 / 负匣人一样走「已见」记录）。

【核心十二：精英与变奏】（R18 新增，敌人侧第一次分化）
  以前四关六房的敌人是同一个模子 —— 打到第二关，你已经不需要「看」，只需要「重复」。
  这一层把差异长在敌人身上：六种精英 + 五种变奏。
  它们**都不是 Boss**：不进 Boss 血条、不锁门、不播 Boss 台词。

  · 六种精英（脚下有精英光环，血条下面还有一条自己的小罡气条）：

      剑修傀儡  阳    血 8  罡气 120   剑阵（范围震波）+ 双持飞剑两连发
                                       → 平砍 10 刀都推不动，必须用凝罡·开山破罡
      符修      阳    血 5  罡气 40    扇形贴符齐射（3 张，带夹角）
                                       → 远程压制，入阴换线绕后
      丹修      阳    血 6  罡气 60    炼丹回血 + 近身点炉自爆
                                       → 拖不得，拖久了它自己炸，而且炸得到你
      怨灵      阴    血 4  罡气 30    阴界追击 + 隔界飞刺
                                       → 锁在阴界，站阳界既看不见也打不到它
      纸人      两界  血 2  罡气 10    每 8 秒剪一个分身
                                       → 剑气纵横清场，别一个一个点
      尸傀      阳    血 12 罡气 100   读招格挡 + 不可格挡的抓取
                                       → 用取消窗口骗招，硬拼会被抓

      注意「血」和「罡气」是两件事：剑修血只有 8 但罡气 120（难在破防），
      纸人血 2 罡气 10（难在数量）。所以六只精英不是六个数值档，是六种解法。

  · 关卡门槛 —— 精英是「越走越深」，不是「一上来就有」：
      第一关（镇钟廊）  一只都没有 —— 第一关是教学关，不放考试题
      第二关（剑冢阶）  剑修傀儡 / 符修
      第三关（尸解墓道）加 丹修 / 纸人
      第四关（天门）    六种全开（含阴界专属的怨灵）
      替换率 15%（不是每间房都有）；精英房不刷、精英身上不带变奏。

  · 五种变奏（叠在**普通杂兵**身上，每只 45% 概率），头顶一枚徽记：

      护 盾   六边形      额外 30 点护盾，每刀磨 10 点，停手 4 秒回满
                          → 连着打，别打一下就跑
      召 唤   三个点      每 8 秒召一只帮手 → 先杀它，否则越打越多
      自 爆   倒三角      贴身 96 像素内点炉，2 秒后炸
                          → 2 秒内砍一刀就打断（见下「可处决窗口」）
      读 招   一只眼      你出刀时 55% 概率提前格挡（CD 2.8 秒）
                          → 假动作骗它格挡，再打真空期
      狂 暴   三根刺      血量 ≤30% 攻速 ×1.5 → 留爆发收尾，别留残血

      徽记是**形状 + 颜色双编码**，不是纯色点 —— 暗背景和小尺寸下颜色读不出来，
      形状读得出来；色盲也能靠形状分。自爆额外有一个越收越紧的倒计时环，
      不用读秒，看环的收缩速度就知道还剩多久。

  · 可处决窗口：自爆变奏点炉后有 2 秒的「可处决」状态。
    这 2 秒里砍中它 → 直接打断、转硬直 1.3 秒。处决第一次有了战术用途，
    不再只是演出。不理它的代价也够高：炸出来是真的疼。

  · 怎么一眼读懂一只敌人：
      脚下有光环 → 精英（去看它长什么样，六种剪影不一样）
      头顶有徽记 → 变奏（去看徽记形状）
      两个都没有 → 普通杂兵，照旧打
    精英的剪影是各自成形的：悬剑环 / 灯笼符 / 炉膛红 / 青环幽体 / 竖纸条 / 肋骨绿。

  · 当时没做的：三把武器的专属绝招，**已在 R18b 做完**（见「核心十三」）。
    当时压着不做，是因为一轮只改一个手感变量 —— 敌人变难和玩家变强同时上线，
    就分不清该归功于哪个改动。

【核心十三：四把武器的绝招】（R18b 新增，R29 加符剑）
  蓄力 1.15 秒（按住「蓄」/ 手柄重击）会放绝招。以前三把武器都是同一招「剑气纵横」，
  现在按武器分成四种**形状**——消耗和总伤害基本一样，只有形状不同。

  · 单 手 剑 · 剑 心 · 一 线
      一道横贯画面的金色直线，一刀 6 点伤害。
      判定 560×84 —— 长、窄，**站定瞄准再放**才有意义。
      适合：拉开距离、瞄着一条线上的敌人一刀到底。

  · 长 枪 · 枪 出 如 龙
      三段推进突刺，每段 2 点（共 6），每段都往前顶 300 像素。
      判定 190×58 × 3 段 —— 短、快、往前压。
      适合：把距离变成伤害，一路推着敌人走。

  · 双 刀 · 双 生 · 旋 刃
      原地六段旋风，每段 1 点（共 6），半径 132。
      判定是圆形，绕着身子打 —— 贴脸最疼。
      适合：被围住的时候原地转，边打边叠护体罡气。

  · 符 剑 · 符 阵 · 万 剑（R29）
      在身前布一个符阵，扇形连射 8 道符，每道 2 点（共 16）。
      判定是 8 个独立弹丸，约 1.6 秒放完 —— 唯一「持续输出」型大招。
      适合：对面正在远处摆架势 / 走位飘忽时，用弹幕把它钉在原地。
      代价：符是单发命中，不穿透；放的时候自己站着不动。

  · 四个都要记住的两件事：
      ① 绝招**不能剑意交锋，也不能被弹反**（和凝罡·开山一样）
      ② 绝招也守「阴阳同界」—— 站在阳界放绝招，同样打不到阴界的怨灵

  · 怎么选：想要「一刀清一条线」选剑；想「推着打」选枪；想「贴脸转圈」选双刀；
    想「站远打弹幕」选符剑。数值一样，选的是打法，不是强弱。

【核心十四：序章 · 钟楼】（R19a 新增）
  第一次开始游戏，不会直接掉进镇钟廊 —— 先进「钟楼」。三层，一层只教一件事，
  全程没有岔路、没有宝箱商人、不掉法宝。这是唯一一块「只让你试一个动作」的空地。

    一 层   移动 + 攻击      1 只道兵傀儡（不还手，只当沙包）

【核心二十二：第 4 把武器 · 符剑与符力】（R29 新增）
  前三把是「近战三态」：剑均衡、枪管空间、双刀管压制。符剑补的是第四种需求 ——
  「我想站远一点打」。它是全项目唯一一把远程 / 近战混合武器，也是唯一一把
  不吃灵力、改吃**符力**的武器。

  · 连招 3 段：符击（远程）→ 符击（远程）→ 剑斩（近战突进，刀锋 86×70）
  · 符力：独立资源，上限 5 格，每秒回 1.1
      - 前两段每段吃 1 格；第三段（近战）吃灵力、不吃符力
      - 符力不够就出不了这一符（头顶冒「符 力 尽」），只能等回
      - 换房 / 复活回满
      - 剑身上有 5 道符，按剩余符力逐道点亮 —— 不看 HUD 也知道还能打几发
      - HUD 里灵力条右边多一条紫条（只在符剑时出现），带 5 格刻度
  · 远程段**没有刀锋**：符飞出去了，手里是空的
      - 打不出近战判定 —— 一次出手不会吃两次伤害
      - 也弹不回落幕弹（符在飞，刀没在手上）
  · 代价：单段伤害最低（远程 1 / 近战 2）、架势压制最低（三段合计 0.18）——
    安全换输出，四把里打「道心失守」最慢的就是它
  · 专属绝招「符阵 · 万剑」：在身前布阵，扇形连射 8 道符（每道 2 伤），
    约 1.6 秒放完 —— 四把武器里唯一「持续输出」型大招
  · 处决「符爆」：符在目标体内炸开，半径 80 内其它敌人各受 1 点并重置护体罡气
  · 无相·心魔照样抄：你拿符剑打它，它的「影 · 符阵 · 万剑」也是扇形射符
  · 符力为什么不是原设计的「每秒回 0.5」：那样每一符要等 2 秒，会把符剑变成
    「站着等回蓝」的武器。调到 1.1 后，一套连招（2 符）净耗约 1 格，
    连打四五套才需要歇一口 —— 有管理感，但不憋屈。

【核心二十三：法宝扩容 · 21 → 33】（R30 新增）
  R13 的法宝位次（刃 / 壁 / 灵 × 3 格，可扩 4）原本配 21 件随机池，凑一套就那几套。
  R30 加 12 件，随机池 21 → 30（另 3 件影系镜像仍不进随机池），
  组合数从 C(8,3) 量级涨到 C(12,3) 量级 —— **深度来自选择，不来自数值**。

  · 设计铁律：**12 件全部带「代价」或「条件」，没有一件是纯加法**。
    所以这 30 件里不存在「数字最大的那件」——每件都在问你愿意付什么。

  【剑位 +4（刃）】
    断 念   剑意交锋把敌方罡气推得更多（40% → 55%）   代价：自身罡气上限 -15
            拼刀型玩家的核心件。用 85 上限换每次交锋多推 15%，
            对「一刀不挨」的人是纯赚，对常吃刀的人是自己给自己挖坑。
    追 风   取消收刀后再出刀，首段伤害 +2（1 → 3）   代价：取消后 0.5 秒不能再取消
            把「取消」从操作习惯变成资源。连消连打伤害爆炸，
            但一旦按错节奏就有 0.5 秒硬直 —— 高风险高回报。
    剑 匣   飞剑类法宝伤害 +1（约 +50%）              条件：没有飞剑类法宝时完全无效
            纯联动件。飞剑 / 剑群 / 穿云 三件里带一件才有意义，
            否则它就是一张白卡 —— 抽卡时看得见代价。
    残 心   连续 3 段不被打断，第 3 段伤害 ×2（2 → 4）  代价：中途挨打则计数清零
            逼你「打完一整套」。打完一套是双倍，被摸一下就归零。

  【体位 +4（壁）】
    铁 衣   气血上限 +2（5 → 7）                      代价：移速 -10%（235 → 212）

    反 震   格挡成功时反弹 1 点伤害给最近的敌人（130 内） 代价：只对近战刀锋有效

    血 怒   气血低于 30% 时伤害 +2；高于 30% 时伤害 -1  代价：满血时反而更弱
            残血战神件。5 血时低于 30% 需要只剩 1 点血 —— 极限反杀流专用。

    聚 灵   道蕴获取 +30%                             代价：气血上限 -1（5 → 4）

    符 囊   符力上限 +2（5 → 7 格）                    条件：不带符剑时完全无效

  【新增机制：会心】
    · 基础暴击率 0.05，但**只有装了阴眼才会参与判定** ——
      没有阴眼时 `crit_chance()` 返回 0，随机数根本不摇。
    · 阴界 +0.20、阳界 -0.10，最终夹在 0 ~ 0.95。
      所以装阴眼后：阴界 25%、阳界 0%（5% 减 10% 被夹到 0）。
    · 会心伤害 ×2，命中时飘「会 心」二字（金色，与普通飘字区分）。
    · 为什么不做成全局 5% 底暴：那会让 R29 的手感被动变化。
      现在「装不装阴眼」是一个明确的玩法分岔，而不是偷偷改了所有伤害期望。

  【新增机制：阴阳界加成】
    · 阴界 / 阳界判定沿用 R18 的 `depth >= 0.5`（越深越阴）。
    · 阴眼 / 阳炎 是第一批「按界分效果」的法宝 —— 同一件在两边表现不同。
    · 这两件也是第一批「互相拆台」的法宝：一起拿 = 两边都只有半效。

  【顺带修掉的底层问题】
    · 气血上限原来写死 `MAX_HP = 5`，铁衣 / 聚灵这种「改上限」的法宝根本没法实现。
      R30 把它函数化成 `max_hp()`，并同步替换了 hud.gd 与 main.gd 里的 2 处引用 ——
      否则血条宽度和实际上限会对不上（这是加完 `max_hp()` 最容易漏的地方）。
    · 拿到铁衣时补 2 点当前血、拿到聚灵时把当前血夹紧到新上限。

  · 一句话记住：**30 件里没有「更好的那件」，只有「你愿意付什么的那件」。**

【核心二十四：兵器铭刻 · 精铁与 2 槽】（R31 新增）
  法宝改的是「你这个人」（气血 / 移速 / 道蕴 / 位次流派）；
  铭刻只改「这把兵器」（取消窗口 / 段位伤害 / 刀锋长度 / 符力）。
  所以两者不抢位：法宝照旧 3 位次，铭刻是兵器自己的 2 个槽。

  · 入口：暂停页底部左边的「兵 器 铭 刻」（键盘 M，或直接点它）。
  · 每把兵器 2 个槽，**按兵器分开记** —— 剑的铭刻跟着剑走，换成长枪就看不到。
  · 精铁（洗练货币）只从「精英 +1 / Boss +2」来，杂兵不掉：
    这是为了让铭刻绑定「难打的东西」，而不是刷小怪刷满。
  · 空槽 → 花 2 精铁刻一条随机词条；已有词条 → 花 3 精铁洗练（重 roll）。
    同一把兵器的两条词条不会重复（抽的时候会排除另一槽已有的）。
  · **局内构筑**：开新局（含读档）清空，不进存档 —— 和法宝的「一局重开清空」同一条规矩。

  【10 条词条】

    通用（4 把兵器都能出）
      锋 铭   首段伤害 +1
      终 铭   连招末段伤害 +1
      疾 铭   取消窗口提前 5%
      反 铭   完美弹反后 1 秒内伤害 +1
      压 铭   护体罡气压制 +10%
      省 铭   出刀灵力消耗 -8%
      长 铭   刀锋判定范围 +6%
      快 铭   出招速度 +5%（前摇 / 判定 / 后摇一起快）

    符剑专属（只出现在符剑的铭刻池里）
      符 铭   符力上限 +1（5 → 6；和法宝「符囊」可叠加）
      迅 符   符击飞行速度 +15%（620 → 713）

  · 为什么符剑要有专属词条：没有这一支，新兵器在铭刻系统里就是二等公民 ——
    它的核心资源（符力）吃不到任何铭刻加成，等于被系统排除在外。
  · 数值都很小（+1 / +5% / +6%）：铭刻是「微调手感」，不是第二个法宝系统。
    真正的量级差在法宝那边，铭刻负责把一把兵器调成你顺手的样子。
  · 快铭只缩段位时长，不改攻速成长与 HUD 读数 ——
    否则「攻速 0.78」这个数字会开始骗人。

  【和法宝的边界（重要）】
    · 法宝：跨兵器、改人、有代价、3 位次容量
    · 铭刻：绑兵器、改刀、纯加法但很小、2 槽固定
    两套系统各自独立结算：伤害层先算法宝再加铭刻，最后统一「至少 1 点」兜底。

【核心二十五：丹药与快捷格】（R32a 新增）

  法宝与铭刻改的都是「常驻数值」；丹药是局内唯一「现在就用掉」的东西。
  它不提升上限，只决定你能不能在某个瞬间把命续回来。

  【三个格子，硬上限】
    屏幕左侧常驻三格，键盘按 1 / 2 / 3，触屏直接点格子。
    · 3 格是**硬上限**，丹药与以后的符箓共用 —— 带什么，就是取舍
    · 同一种最多叠 3 个；叠满后再捡到同种不会另开一格
    · 服丹有 0.9 秒冷却（防连点把血刷满）
    · 开新局清空；进存档不进存档？—— **不进**，和铭刻、精铁一样是局内资源

  【六味丹药】

    回 春 丹   气血 +2                    38 道蕴
    聚 灵 丹   灵力 +50（顺带解除力竭）    26 道蕴
    罡 气 丹   护体罡气 −40                24 道蕴
    破 境 丹   10 秒伤害 +2，但受伤也 +1   55 道蕴
    洗 髓 丹   清全部负面状态              34 道蕴
    九 转 丹   致死时自动复活一次          90 道蕴

  【「用了没意义」会被拒绝】
    血满时吃回春丹、灵力满时吃聚灵丹、罡气本来就是 0 时吃罡气丹 ——
    不会白吃，也不会扣数量，只在顶部提示一句。这条很重要：
    消耗品最烦的不是弱，是「按了没反应，不知道到底吃没吃」。

  【九转丹是唯一的自动丹药】
    它是「致死时自动触发」的，主动按 1/2/3 吃会被拒绝并说明原因。
    本局只保一次命：第一次致死 → 回 2 点血 + 2 秒无敌；第二次就真死了。
    要不要把它占掉一个格子，是这一层最实在的决策。

  【破境丹是「拿命换刀」】
    10 秒内每刀 +2 伤害，同时受到的伤害 +1。
    它不会让战斗变简单，只会让「这 10 秒」变成一个必须用掉的窗口。
    HUD 会在格子标题旁显示「破境 8.4s」倒计时。

  【从哪来】
    · 宝箱第一选项：法宝 + 20 道蕴 + 丹药 1 粒（均等随机）
    · 商队第 4 行：一味丹药，价格照表
    · 精英怪 35% 掉 1 粒（带权重，九转丹只有 10%）
    · Boss 必掉 1 粒
    · 三格满了再得丹 → 折 8 道蕴，不会白捡

【核心二十六：符箓与纸人】（R32b 新增）

  丹药是「把自己修回来」，符箓是「把这一瞬间的战场改掉」。
  两者**共用那三个格子**——这是 R32 真正的重量所在：
  带三粒丹是稳，带三张符是险，带两张符一粒丹是赌。

  【六种符箓】

    火 符   前方 200 范围火墙，每段 2 点      30 道蕴
    雷 符   五道天雷随机落下，各 1 点         34 道蕴
    盾 符   3 秒无敌                         44 道蕴
    遁 符   向前瞬移 300（前方无路则拒绝）    28 道蕴
    召 符   纸人替你打 10 秒                  48 道蕴
    封 符   全场定身 2 秒（Boss 只吃 0.8 秒） 40 道蕴

  【符箓是「世界侧」的】
    丹药全部在玩家身上结算；符箓不一样——火墙、天雷、纸人、定身，
    都是关卡的事。所以玩家甩符时只发四道信号（火 / 雷 / 召 / 封），
    由关卡去落地。好处是：以后加符不用再改玩家，改关卡就行。

  【纸人（召符）】
    一个 10 秒的纸傀儡，跟你同深度、永远画在你身后（z_index −1）。
    · 只沿 x 轴追敌，**绝不换深度**——它的 y 永远跟着你
    · 索敌要过 lane_ok（深度容差 0.26），隔着深度线的敌人它看不见
    · 拴绳 420 像素：你跑太远它会停在原地，不会把敌人引到别处
    · 攻击 1 点，1.05 秒一刀，够打断小怪的前摇，打 Boss 只算挠痒

  【封符对 Boss 打折】
    杂兵定身 2 秒（够你砍一轮半）；Boss 只吃 0.8 秒（0.4 倍）。
    这不是「削弱符箓」，是「不能让一张 40 道蕴的符直接废掉 Boss 的所有招式」。
    被定住的敌人照样掉血，只是不动。

  【遁符会拒绝】
    前方 60 像素内有墙时，遁符**不消耗**，只提示「前 方 无 路」。
    理由和丹药一样：消耗品最烦的不是弱，是白扔。

  【从哪来】
    · 商队第 5 行：一张符箓，价格照表
    · 精英怪 18% 掉 1 张（比丹药的 35% 低——符箓更强，就更稀）
    · Boss 必掉：1 粒丹 + 1 张符
    · 三格满了再得符 → 折 8 道蕴

【核心二十七：道痕与经脉】（R33a 新增，R33b 扩到 24 条）

  前面二十几层全是「这一局」的事。经脉是第一条**跨局**的线：
  死了也算数，而且只改手感、不改运气。

  【道痕 ≠ 道蕴（念出来不一样）】
    道蕴：局内的钱，买法宝 / 扩格 / 服丹，**开新局归零**。
    道痕：局外的点数，只用来点经脉，**跨局保留**，不进任何存档槽。
    规划稿里本来叫「道韵」—— 但「道韵」和「道蕴」同音，念出来分不开，
    所以改叫「道痕」：走到底的人，总归留下一点痕迹。

  【道痕怎么来】
    · 死亡：4 + 4 × 关序 + 清房数 / 3
      → 第 1 关速死也有 4 点。**这是设计**：肉鸽的「输了也变强」
        必须当场兑现，不能等到通关才给
    · 通关：60 + 10 × 关序
    · 今日道劫：上面两个数再 ×1.5
    · 一局只结算一次（死亡 / 胜利两条路径不会重复发）

  【三脉 × 8 条 = 24 条，每条 3 级（共 72 级）】

    剑 脉（改「刀」—— 全是进攻手感）
      剑 锋   收刀可取消窗口提前      5 / 10 / 15%
      御 剑   符击飞行速度            7 / 14 / 21%（满级穿透 1 个）
      剑 心   剑意交锋完美窗口        6 / 12 / 18%
      剑 影   冲刺灵力消耗            −8 / −16 / −24%
      出 锋   出刀前冲距离            +6 / +12 / +18%
      刀 锋   刀锋判定范围            +4 / +8 / +12%
      快 剑   攻速成长上限            +3 / +6 / +9%
      气 脉   热度上升速度            8 / 16 / 24%（满级回落 −50%）

    体 脉（改「身」—— 全是挨打之后怎么站起来）
      血 气   受伤后无敌帧            8 / 16 / 24%
      罡 气   护体罡气上限            +6 / +12 / +18
      格 挡   格挡灵力消耗            −8 / −16 / −24%
      体 魄   移速                    +3 / +6 / +9%
      铁 骨   挡刀后的硬直            −10 / −20 / −30%
      真 气   精准格挡后罡气驻留      +10 / +20 / +30%
      体 韧   灵力延迟回复            −10 / −20 / −30%
      凝 神   精准格挡判定窗口        +6 / +12 / +18%

    灵 脉（改「息」—— 全是资源与身法）
      灵 息   灵力上限                +8 / +16 / +24
      聚 灵   灵力回复                7 / 14 / 21%
      符 丹   服丹 / 甩符冷却         −10 / −20 / −30%（满级开局送 1 粒丹）
      道 蕴   道蕴获取                6 / 12 / 18%（满级开局 +10 道蕴）
      符 力   符力回复                7 / 14 / 21%
      灵 贯   符力上限                +1 / +2 / +3
      神 行   冲刺冷却                −6 / −12 / −18%
      丹 火   打坐回血的道蕴消耗      −8 / −16 / −24%

    价格：升 1 / 2 / 3 级各 20 / 40 / 70 道痕；
          全树 72 级共 3600（单脉点满 1200，约 15 局通关）。
    洗点：退回已投入的 70%（投 150 退 105）。

    「快剑」只抬**顶**不抬**底** —— 起手依旧慢，只是连打能爬得更高。
    「灵贯」给的是点数不是百分比 —— 符力只有 5 点，+3 已经是六成，
    按百分比算会失控。

  【两条硬约束（写进代码注释了）】
    ① **不改随机性**：经脉只碰「已经存在的」手感访问器
       （移速 / 灵力上限 / 取消窗口 / 无敌帧…），法宝池一件都不动。
       所以「这局拿到什么」永远是随机的。
    ② **不能碾压难度**：每级 ≤ +10%。满经脉大约等于「多一条命」，
       不是「挂着就能通关」。

  【怎么用】
    标题页第 5 行「经 脉 · 丹 房」进去。R33c 起是**四页签**：
    顶部四个页签（1 剑脉 / 2 体脉 / 3 灵脉 / 4 丹房），一页只显示一脉的 8 条，
    2 列 × 4 行；每格显示 名字 / 三级刻度点 / 当前效果 / 下一级效果 / 价格。
    · 键盘：↑↓ 选行，←→ 换列，**1 / 2 / 3 / 4 切页签**，空格 升级，
            R 洗点，Esc 返回
    · 触屏：点顶部页签切页，**点一下卡格选中，再点一下才升级**（两下才花钱）
    · 选中的那条如果满级有额外效果，底部会单独写一行
    · 页签下面一行会显示「本脉 N / 24 级」，切脉时一眼看到这一脉点到哪了

【核心二十八：丹房 · 局外合成】（R33c 新增）

  经脉解决「道痕能变成什么」，丹房解决「道痕还能变成什么」。
  两条路抢同一笔钱 —— 这才是取舍。

  【价目表（单位：道痕）】
    回 春 丹  19        火 符  15
    聚 灵 丹  13        雷 符  17
    罡 气 丹  12        盾 符  22
    破 境 丹  28        遁 符  14
    洗 髓 丹  17        召 符  24
    九 转 丹  45        封 符  20

    价 = 商队价的一半。一局通关 80 道痕 ≈ 4 味便宜丹，或 1 粒九转丹。
    为什么打折：道痕比道蕴稀有得多（一局道蕴常有几百），照抄商队价会变成
    「买不起的橱窗」。

  【三条规矩】
    ① **背包只有 9 件**（= 快捷格 3 × 每格叠 3）
       背包不会比「一局能带的」更大，所以炼了就得带，带了就得用，
       不存在「攒着不用」的仓鼠玩法。
    ② **开局自动带进快捷格，然后背包清空**
       带进去就归这一局：局内用掉就没了，死了也不还。
       丹房不是保险箱，是「提前下注」。
    ③ **货架固定 12 张，不搞随机**
       丹房的作用是兑现，不是抽奖。攒够道痕却买不到想要的，是新的挫败源。

  【怎么用】
    标题页第 5 行「经 脉 · 丹 房」进去 → 顶部第 4 个页签「丹房」。
    12 张方子排成 4 列 × 3 行，每格显示 字徽 / 名字 / 效果 / 价 / 已存几件。
    · 键盘：↑↓←→ 选方子，空格 炼制，1 / 2 / 3 / 4 切页签，Esc 返回
    · 触屏：点页签切页，点方子选中，**再点一下才炼**（两下才花钱，防误触）
    · 选中方子的效果会在下方单独念一遍（卡片里的字小，看久了累）
    · 丹房页不显示「洗点」—— 洗点只对经脉有效


【核心二十九：背景音乐（BGM）】（R34 新增）

  三十余轮零声音的游戏，终于有声音了。这一层**不引入任何外部音频素材**，
  四段 BGM 全部由 Python（tools/gen_music.py）程序化合成 —— 钟体非谐分音
  （1 / 2 / 2.76 / 5.40 / 8.93 泛音比）叠加低吟 drone，做无缝循环，
  贴合「正在熄灭的钟」的世界观。

  【四段曲目（music/ 目录，共约 4 MB）】
    title    标题页 / 终局      20s 循环，钟声最完整、最空
    explore  普通房间 / 走廊     28s 循环，行进感、带轻微金属回声
    boss     Boss 房            24s 循环，低音更重、节奏更逼
    daily    今日道劫（每日种子） 24s 循环，比 explore 更冷、更薄

  【怎么响】
    新增 autoload 脚本 scripts/music.gd（挂载在 /root/Music），
    双 AudioStreamPlayer（_a / _b）交叉淡入淡出 —— 切曲时新曲渐入、
    旧曲渐出，不会「啪」地断。每帧用 move_toward 逼近目标音量（dB），
    70 dB/s 的淡变速度听不出接缝。
    · 标题页：Music.play("title")
    · 进房间前按场景选曲：Boss 房 → "boss"；今日道劫 → "daily"；其余 → "explore"
    · 同曲重复调用会被忽略（不会重启循环）；stop() 把双路都归零

  【两个实现要点】
    ① Godot 4.7 的循环属性是 `loop_mode = AudioStreamWAV.LOOP_FORWARD`
       （不是旧版的 bool `loop`）—— 自测 T161 用注入的静音 WAV 验证
       切曲 / 同曲忽略 / stop 归空全链路。
    ② 导出时 Godot 会把 res://music/*.wav 重新导入并打进包
       （导出日志确认 music/*.wav.import 生成、APK 体积增量吻合），
       所以资源层不依赖本机 .import 缓存。

  【已知边界】
    无头环境无法验声（与往轮同理），自测只做到「文件合法 + 管理器逻辑正确」；
    **真机音频（手机 / PC）需实机听一遍确认** —— 这一层是真机上最能拉开
    「能看」与「能沉浸」差距的一轮。


【核心三十：灵兽与傀儡（同伴）】（R35 新增）

  铁律一句话：**同伴不抢操作权**。灵兽全自动，傀儡只跟随不指挥 ——
  本作不做 RTS。`companion.gd` 全程不读 Input，也绝不移动玩家
  （自测 T165 直接扫源码 + 跑 60 帧验证玩家坐标不变）。

  【灵兽 · 跟随 1 只，被动、不参与战斗判定】
    白 狐   输出   每 5 秒吐一次狐火，伤最近敌人（伤害 = 等级）
    玄 龟   防御   每 10 秒给玩家 1 层护盾（挡 1 次）；2 级起间隔缩到 8 秒
    青 鸟   辅助   每 8 秒回 20 灵力；2 级起顺带回 1 点气血
    · 灵兽**打不死**（hp 视为 9999，hurt_companion 对灵兽直接返回）
    · 等级越高技能越强：狐火伤害 = 等级；护盾层数 = 等级；回灵 = 20 × 等级

  【傀儡 · 可多个，跟随作战、有 HP 会死】
    剑 傀 儡   跟着玩家砍最近的敌人（1.2 秒一刀，近战）
    盾 傀 儡   站到玩家与最近敌人之间挡刀，每 6 秒给玩家护盾；血最厚（10）
    符 傀 儡   退到远处放符，复用弹幕通道；血最薄（5）
    · 傀儡被附近敌人蹭血会掉血，归零即「碎」——死了不会复活

  【怎么获得】
    · 精英房掉一颗**灵兽蛋**（6 种同伴随机），走到附近（<64）即获得
    · 一局内 companions 数组累积；回标题 / 死亡时清空（局内构筑，不进存档）
    · HUD 左侧「位次」下面列出一行同伴：灵兽只显名，傀儡显「血/上限」

  【法宝联动】
    「灵 契」（灵位法宝）：同伴伤害 +50%，代价是气血上限 -1 ——
    想靠同伴打输出，就得自己少挨一刀。

  【数值（scripts/companion.gd）】

【核心三十一：符箓秘境 · 符阵场与符祖】（R36 新增）

  第 5 关。天门之后、轮回台之前 —— 一个「地面会咬人」的关。

  【符阵场（这关的机制变奏）】
    房间里会亮起一圈圈符阵，**踩上去触发一次就熄**：
      生 符（绿圈）  灵力 +12
      煞 符（红圈）  扣 1 点气血
    · 生煞按房间里的序号奇偶交替，位置前后交错 —— 想全吃生符，
      就得在两界（阴 / 阳）之间来回走，而不是直线冲过去
    · 一次性：踩过就暗掉；**重进这间房会重新亮起**，所以每趟都得重新算路线
    · 它是房间物件，只读你的坐标、只改你的资源 —— 不接管任何操作

  【符祖（关底 Boss）】
    本作第一个**纯远程 Boss**：
    · 不贴身：你压上去它就后退，拉开到中距离再站住
    · 五连扇形「画符齐射」：每 2.6 秒一轮，五张符呈扇形罩过来
    · 周期性「画符封路」：地面符爆（范围攻击），逼你别站桩
    · 两阶段（第 1/2 阶段），血量 16，硬直条 150
    打法：别在远处和它对射 —— 贴上去逼它退到墙角，它就只能近身拍你。

  【关卡结构（3×2 六间房）】
    符阵·前庭（起点）→ 朱砂·回廊（3 符阵）→ 秘藏·符龛（宝箱）
    → 残符·深处（陷阱 + 2 符阵）→ 符祖·祭坛（精英 + 3 符阵）→ 符祖·殿（Boss + 2 符阵）

  【为什么插在心魔境之前】
    心魔境是「镜子里的你」，必须还是最后一关（真结局挂终章）。
    所以新关插在它前面：符箓秘境是第 5 关，心魔境顺延为第 7 关，
    `finale_level()` 指向它。原 4 关的 Boss 编号一个没动（自测 T170 守着这条）。


【核心三十二：轮回台 · 旧影与轮回使】（R37 新增）

  第 6 关。符箓秘境之后、心魔境之前 —— 一个「影子会咬人」的关。

  【旧影（这关的机制变奏）】
    房间里站着几个**半透明的影子**，脚下有一圈淡紫光。
    它们不是新敌人 —— 它们是**你刚才那几秒的走位**：
      · 游戏一直在记录你的坐标（每 0.1 秒一个点，保留最近 40 个 ≈ 4 秒）
      · 旧影拿到这段轨迹，就沿它再走一遍 —— 你绕圈，它也绕圈
      · 碰到扣 1 点气血；存在 8 秒后自行消散
    · 所以「一直绕圈磨」在这关是负收益：你的路线越规律，影子越贴你
    · 正解是**打破自己的节奏** —— 走直线、突然折返、利用深度换道
    · 与符阵一样：只读你的坐标、只扣你的血，不接管任何操作

  【轮回使（关底 Boss）】
    与上一关的符祖**正好相反**的压迫型：
    · 全场最快的 Boss（移速 172，比域外天魔还快），贴身死缠
    · 每 7.5 秒（第 2 阶段 5.5 秒）现场召 2 只（第 2 阶段 3 只）旧影
    · 召唤**不打断追击** —— 它不会站着让你白打
    · 两阶段（第 1/2 阶段），血量 18，硬直条 140
    打法：别指望拉开距离，这关拼的是「你的走位能不能让它学不到东西」。

  【关卡结构（3×2 六间房）】
    轮回·前庭（起点）→ 旧影·回廊（2 旧影）→ 秘藏·轮藏（宝箱）
    → 因果·深处（陷阱 + 2 旧影）→ 轮回使·祭坛（精英 + 3 旧影）→ 轮回使·台（Boss）

  【为什么还是插在心魔境之前】
    心魔境仍必须是最后一关。R37 之后关卡表 7 关：
    符箓秘境（5）→ 轮回台（6）→ 心魔境（7，终章）。
    `finale_level()` 一律返回 `LEVELS.size() - 1`，所以再加关也不用改代码。

  【R37 顺手修的一个真 bug】
    `enemy.gd::is_elite()` 原本写「kind >= 8 且 kind != 14」，
    而 Boss 编号 15（符祖）、16（轮回使）都 ≥ 8 —— 它们被判成**精英**，
    走的是 `_elite_ai` 和 `_draw_elite`：符祖的五连扇形 / 后退走位**从未真正生效**，
    外形也一直是精英的样子。改为「排除整个 Boss 家族」后两关的 Boss 才真正按设计跑。
    自测 T175 专门守这条（8 个 Boss 编号都不能被判成精英）。


【核心三十三：因果业力 · 三结局与魔剑】（R38 新增）

  这一轮不加关、不加 Boss。加的是「你怎么打」—— 同样的关，可以有三种走法。

  【业力（正 = 魔道，负 = 天道）】
    处 决         +1    赶尽杀绝
    普通击杀       0    各为其主，不算账
    放 走         −1    手下留情
    · 只在局内累计，每局清零；夹在 ±99
    · 结算页显示「业 力 +7 · 魔 道」，颜色随分支变（魔道赤红 / 人道素白 / 天道青绿）

  【「放走」怎么触发 —— 不是新按键】
    敌人被打到**道心失守**（护体罡气破了、身体泛红，可以按 F 处决）时，
    你**什么都不做**，等那个窗口自己走完 —— 这一命就算放走的。
    · 窗口长度：普通敌人 2 秒，Boss 1.2 秒
    · 所以「放走」不是按出来的，是**忍住不按**出来的
    · 代价是实打实的：少一次处决的伤害与收益，换一份清白

  【三结局】
    业力 ≥ +5     魔 道     剑下无活口　业火自焚身
    −4 ~ +4       人 道     杀与不杀　各有其时
    业力 ≤ −5     天 道     道心不染　过手皆生
    · 只换结算页的分支名 / 颜色 / 短评，不改难度、不锁内容
    · 与真结局**正交**：真结局看「你走到了哪里」，业力看「你一路怎么走」

  【魔剑（新法宝，剑位）】
    业力 ≥ +5 才会出现在奖励里（宝箱 / 精英掉落 / 险路）
    · 处决伤害 ×2，处决后回 1 点气血
    · 代价：气血上限 −1
    · 正反馈闭环：处决越多 → 业力越高 → 越容易遇到它 → 处决更强 → 更魔
    · 业力不够时它根本不在池子里，不会占你的三选一

  【为什么没做规划稿里的「符丹 −1」】
    原规划写「处决 +1 / 普通 0 / 符丹 −1 / 放走 +2」。
    但代码里并没有「用符丹收服敌人」这条路 —— 硬造一个等于凭空加一套系统，
    违背「一轮只让玩家学一件事」。所以按现有机制重映射成「处决 / 普通 / 放走」三分法：
    三条全部落在已有的「道心失守」窗口上，零新操作、零新界面。

【技术说明】
  · 引擎：Godot 4.7.2（GL Compatibility 渲染）
  · 美术：零素材，全部用 GDScript 的 _draw() 程序化绘制
  · 2.5D（R9）：每个实体带一个深度 z，渲染时用 draw_set_transform 绕"脚底原点"
    整体缩放 + 上抬，再用 z_index 排序；判定层依旧是纯 2D 矩形比较，
    只在命中前多一道 lane_ok 深度校验。所以没有 3D 引擎、没有 3D 物理，
    但拿到了近大远小 / 近低远高 / 前后遮挡 / 纵深走位四件事。
  · 视差：远景 0.10 / 0.12 / 0.30 / 0.55，后墙 0.75，近景 1.26
  · 音效：tools/gen_sfx.py 用纯 Python 合成 WAV
  · 字体：Noto Sans SC（SIL OFL 开源）
  · 判定：不用 Area2D，而是每帧比较矩形相交，优先级为
    剑意交锋 > 格挡/受伤 > 命中敌人 > 尖刺
  · 安卓导出：同一份工程 + export_presets.cfg 里的 "Android" 预设
    渲染 OpenGL ES 3.0（GL Compatibility），arm64-v8a 单架构，
    未启用 gradle 构建（直接打包模板 APK），minSdk 24 / targetSdk 36
  · 触屏层（scripts/touch.gd）不写任何游戏逻辑，只把手指按下/抬起
    翻译成 Input.action_press / action_release，所以键盘和触屏共用同一套操作
