# 玄界 XUANJIE · 纵深扩展总纲（R29 → R37）

> 本文档回答一个问题：**池子不够深的时候，加关卡只会让换皮感更明显。**
> 所以先补「可组合的东西」，再补「消耗品 / 局外成长 / 同伴」，池子够了才加关卡。
>
> **重编号说明（重要）**：原始规划稿写的是 R24 → R30，那是按「R23 今日道劫」为
> 最后一轮算的。项目实际已经走到 R28（R24 第 13 卷「镜」/ R25 终局演出 /
> R26 影绝招精进 / R27 文档对账 / R28 道劫评分），所以本文档把整条路线整体后移，
> 改为 **R29 → R39**，并把规划里过时的数字按代码实际情况重算（见下表）。

## 二、R29 · 第 4 把武器「符剑」+ 符力 ✅ 已实现

前三把是「近战三态」：剑均衡、枪管空间、双刀管压制。符剑补的是第四种需求——
**「我想站远一点打」**，同时是唯一一把不吃灵力、吃**符力**的武器。

| 项 | 值 |
|---|---|
| 定位 | 远程牵制 + 近战收尾 |
| 连招 | 符击（远程）→ 符击（远程）→ 剑斩（近战突进） |
| 标签 | `ranged / ranged / slash` |
| 架势压制 | 0.04 / 0.04 / 0.10 = **0.18（四把里最低）** |
| 取消窗口 | 40% / 45% / 50% |
| 资源 | **符力**：5 格，每秒回 1.1，远程段各吃 1 格 |
| 专属绝招 | 符阵 · 万剑（8 段 × 2 伤，扇形弹幕，约 1.6 秒） |
| 处决 | 符爆（目标 + 半径 80 内各 1 点，并重置护体罡气） |

**三条硬约束（都已用自测锁死）**
1. 远程段**没有刀锋**：`attack_rect()` / `clash_rect()` 返回空 —— 一次出手不会
   同时吃近战判定，也弹不回落幕弹。
2. 符力不够**出不了这一符**，不进入出刀状态，符力不会被扣成负数。
3. 无相·心魔照抄：玩家换符剑后，它的「影 · 符阵 · 万剑」也是扇形射符
   （`enemy.gd::_mult_fire_one` 补了 `array` 分支，否则影·绝招会变成零判定空招）。

**数值偏差记录**：规划稿写「每秒回 0.5」。实装改成 1.1 —— 0.5 意味着每一符要等
2 秒，会把符剑变成「站着等回蓝」的武器。1.1 下每套连招净耗约 1 格，连打四五套
才需要歇一口。

## 三、R30 · 法宝扩容 21 → 33 ✅ 已完成（2026-10-28）

涨到 C(12,3) 量级 —— 决策空间翻三倍，这才是肉鸽的深度来源。

**设计原则**：每件都要**有条件或代价**，不做纯加法。每件都要和现有机制咬合，

## 六、R33 · 经脉天赋树（局外永久成长）

> **实装拆分（2026-10-28）**：R33 拆成三轮 ——
> **R33a（道痕 + 12 节点 + 经脉页，✅ 已完成）**、
> **R33b（扩到 24 节点 + 三脉页签，✅ 已完成）**、
> **R33c（丹房 · 局外合成，✅ 已完成）**。一轮只改一个手感变量 ——
> 12 条经脉已经要接 12 处接口，一次接完必然出错。
>
> **为什么是 24 而不是一次到 36**：12 条只够玩七局（每脉 4 条 × 150 = 600 道痕，
> 通关一局给 80）。补到 24 条后单脉点满要 1200（约 15 局），节奏刚好；
> 再往上就要先解决「36 张卡怎么排」的排版问题，那是 R33c 之后的事。

> **货币改名：道韵 → 道痕**。规划稿写的是「道韵」，但局内货币叫「道蕴」，
> 两者同音（dào yùn），念出来完全分不开 —— 违反本节自己写的「命名上要能一眼分开」。
> 改成「道痕」：既不同音也不同字，且贴合「走到底的人会留下痕迹」。

**玄界最大的缺口**：现在每局重来，除了「已见台词」与「残卷收集」，没有跨局积累。
肉鸽需要「即使这局输了，我也变强了一点」的钩子。

- **货币：道韵**（跨局保留）。死亡给少、通关给多。
  注意与局内「道蕴」是两种东西，命名上要能一眼分开。
- **三脉 × 12 节点**：剑脉（剑系 / 飞剑 / 剑意交锋）、体脉（气血 / 罡气 / 格挡）、
  灵脉（道蕴 / 符箓丹药 / 灵御）
- 每节点 3 级，越高级越特殊：不是「剑伤害 +1」，而是「取消窗口提前 5%」
  「飞剑可以穿透 1 个敌人」
- 可花少量道韵洗点

## 十、R39 · 钟楼旧主　→ ✅ 已实现（2026-10-29）

规划稿写「隐藏 Boss：无伤通过序章触发，体修，教完美弹反」——
**这轮按原意落地了**，但落地时把「教」这件事做成了机制而不是台词：

- 触发判 `Game.dmg_taken` 的差值（不是 hp）—— hp 会被打坐回血掩盖，
  受击次数不会。「无伤」的准确含义是「一次都没被打中」
- Boss 参数走极端：**移速 96（全场最慢）/ 硬直 190（全作最高）/ 前摇 0.62s（最长）**
- `_decide()` 里直接 `return`，不读招、不瞬移、不远程、不防御 —— 只有一记慢刀
- 进圈就停住不贴脸，给玩家留弹反距离

> **为什么这比原稿更进一步**：原稿只说「教完美弹反」，但没说怎么教。
> 实际做法是**让硬直条高到砍不动** —— 玩家砍得越急越吃亏，
> 只有站住、等他抬手、弹，才打得动。这样「停手」是被机制逼出来的，
> 不是被文案提示出来的。
>
> 打输不惩罚：序章没走完 → `prologue_done` 仍为 false → 下次开新局可重试。

**踩到的坑（已写进 MEMORY.md）**：
`rooms = RoomScript.prologue_rooms()` 拿到的是 `const PROLOGUE["rooms"]` 的**引用**，
`append()` 会失败并中断整个函数 —— 顶阁一直进不去。必须先 `duplicate()`。

## 十三、风险 / 注意

- **符剑的符力管理不能太重**：5 格、1.1/秒是 R29 的初值，需要真机调。
  太重会让符剑变成「等回蓝」的武器，太轻则没有管理感。
- **经脉不能碾压难度**：满经脉 ≈ 多 1 条命，不是无敌。每级节点效果不超过 +10%。
- **丹药 / 符箓不能替代操作**：快捷格 3 格是硬上限，且大部分有 CD 或数量限制。
- **灵兽 / 傀儡不能抢操作权**：全自动、只跟随不指挥，避免变成 RTS。
- **业力不能是道德审判**：只是「这局怎么打」的标签，不影响难度，只影响叙事分支。
- **多周目不能只是数值叠加**：必须有新招式、新词条、新剧情。
- **新增内容必须同时改三处**：代码 / `玩法说明.txt` / `docs/*.md`。
  R27 的教训是「只改文档没改运行时 UI 等于没改」，R28 的教训是反过来也成立。
